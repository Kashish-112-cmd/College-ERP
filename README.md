 # College ERP System

## Project Description

The College ERP System is designed to manage college-related academic activities.

## User Roles

- Student
- Faculty
- Administrator

## Features

1. Student Login
2. View Student Profile
3. View Attendance
4. View Examination Results
5. View Timetable
6. Faculty Adds Attendance
7. Faculty Uploads Notices
8. Admin Manages Students

## Version Control

Git is used to track changes in the project.

GitHub is used to host the repository and support collaboration.

Commits record changes made to the project files.
